# Required MIS report mapping

1. Current-day live sales report (shop ID, transaction/snapshot cutoff, FL/Beer/CL/value/BL)
2. Same-day-last-year report with matching cutoff, or transaction-level LY data
3. Current month-to-date report
4. Last-year same-month-to-same-date report
5. MGR lifting report
6. Dispatch / stock-in / closing stock report
7. POS scan compliance report
8. Licence and shop master

The dashboard must label comparisons as **same-cutoff** or **full-day**; it must never silently compare partial current-day data with a complete LY day.
